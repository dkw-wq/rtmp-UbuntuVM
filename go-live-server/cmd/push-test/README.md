# push-test

`push-test` is a Linux-friendly RTMP test publisher for server and player checks.
It builds into one Go executable, then uses the local `ffmpeg` binary to generate
and publish a synthetic stream.

The generated test stream contains:

- color-changing SMPTE-like moving video from FFmpeg `testsrc2`
- an on-screen running timer overlay
- optional sine-wave AAC audio

## Build

```bash
cd go-live-server
go build -o push-test ./cmd/push-test
```

Runtime dependency:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg
```

## Push With Stream Key And Token

Use a `stream_key` and `push_token` generated by the server:

```bash
./push-test \
  -rtmp-base rtmp://127.0.0.1:1935/live \
  -stream-key '<stream_key>' \
  -token '<push_token>'
```

For remote SRS:

```bash
./push-test \
  -rtmp-base rtmp://jfznbx.cn:1935/live \
  -stream-key '<stream_key>' \
  -token '<push_token>'
```

## Push With Full URL

```bash
./push-test \
  -push-url 'rtmp://jfznbx.cn:1935/live/<stream_key>?token=<push_token>'
```

## Generate MP4 And Loop-Push It

Generate a local MP4 test file and then loop-push that file:

```bash
./push-test \
  -push-url 'rtmp://127.0.0.1:1935/live/<stream_key>?token=<push_token>' \
  -make-mp4 /tmp/srs-test.mp4 \
  -file-duration 30s
```

Generate only the MP4 file:

```bash
./push-test -make-mp4 /tmp/srs-test.mp4 -file-duration 30s
```

Push an existing file:

```bash
./push-test \
  -push-url 'rtmp://127.0.0.1:1935/live/<stream_key>?token=<push_token>' \
  -file /tmp/srs-test.mp4
```

## Useful Options

```bash
./push-test -h
```

Common examples:

```bash
# Push for 2 minutes, 720p, 30 fps, 2-second GOP.
./push-test -push-url "$PUSH_URL" -duration 2m -size 1280x720 -fps 30 -gop 60

# 1080p test stream.
./push-test -push-url "$PUSH_URL" -size 1920x1080 -video-bitrate 4000k -gop 60

# Disable audio if the player under test does not need it.
./push-test -push-url "$PUSH_URL" -no-audio

# Print the generated ffmpeg command.
./push-test -push-url "$PUSH_URL" -print-command
```

For stable HLS playback with the current SRS config (`hls_fragment 4`), keep GOP
at or below 2 seconds: `-gop 50` for 25 fps or `-gop 60` for 30 fps.
